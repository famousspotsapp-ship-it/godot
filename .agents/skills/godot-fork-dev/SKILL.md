# Working in this repository

This is a fork of `godotengine/godot` at engine version **4.7-beta**
(`version.py`), plus one extra top-level directory, `steel_streets/`, holding a
standalone Godot game project. The engine sources are unmodified upstream, so
upstream compiling/contributing docs apply; the notes below are the parts that
are specific to this fork and to the preconfigured dev VM.

## Build the engine (Linux)

```bash
scons tests=yes target=editor dev_build=yes -j$(nproc)
./bin/godot.linuxbsd.editor.dev.x86_64 --headless --test        # unit tests
./bin/godot.linuxbsd.editor.dev.x86_64 --headless --test --test-case="*AnimationPlayer*"
```

Environment notes verified on the dev VM:

- `scons` is installed under pyenv and is **not** on the default `PATH` of a
  non-interactive shell. Use `/home/ubuntu/.pyenv/shims/scons`, or prepend
  `$HOME/.pyenv/shims` to `PATH`, otherwise the build command fails with
  `scons: command not found`.
- Linking needs roughly 8 GB. The VM has 8 GB RAM and an 8 GB `/swapfile` that
  is **not** active at session start — run `sudo swapon /swapfile` before the
  first build or linking can be OOM-killed.
- A clean build takes tens of minutes; incremental rebuilds are cheap. There is
  no prebuilt binary in `bin/` at session start.
- Two optional dependencies are missing, and SCons only warns about them:
  `wayland-scanner` (Wayland support disabled) and AccessKit
  (`python misc/scripts/install_accesskit.py`, or build with `accesskit=no`).

## Lint

There is no `make lint`; style is enforced by pre-commit (clang-format,
clang-tidy, ruff, mypy, codespell, JSON schema checks — see
`.pre-commit-config.yaml`):

```bash
pip install pre-commit && pre-commit install    # once
pre-commit run --files <changed files>
```

## Steel Streets game (`steel_streets/`)

```bash
godot --path steel_streets                                        # any 4.3+ editor/binary
./bin/godot.linuxbsd.editor.dev.x86_64 --path steel_streets       # a build from this repo
python3 steel_streets/tools/gen_assets.py                         # regenerate art + audio (needs Pillow)
```

- `steel_streets/ARCHITECTURE.md` is the accurate description of how the game is
  wired (autoload `GameManager`, procedurally generated level, `AnimatedSprite2D`
  + `AnimUtil` animation, timer-driven combat). Prefer it over the generated
  repository wiki, which attributes AnimationPlayer/AnimationTree/shader-based
  mechanics to the project that do not exist in the code.
- All sprites and WAVs under `steel_streets/assets/` are generated by
  `tools/gen_assets.py`; edit the generator, not the binary assets.
- `project.godot` declares the `4.3` feature tag while the engine here is
  4.7-beta — keep the project on 4.3-compatible APIs unless the tag is bumped.
- Nothing in `steel_streets/` is compiled by `scons` or exercised by the
  engine's GitHub Actions workflows; game changes are only validated by running
  the project.

# Fork notes

This repository is a fork of [godotengine/godot](https://github.com/godotengine/godot).
Everything outside `steel_streets/` is unmodified upstream code; this file
records what is different here and how the team works in it, so generated
documentation and new contributors start from accurate context.

## Delta from upstream

- Base: upstream `master` at `4.7-beta` (`version.py`: `4.7.0.beta`).
- Only addition: `steel_streets/` — a Game Boy-style beat-'em-up demo project
  (see [`steel_streets/README.md`](steel_streets/README.md) to run it and
  [`steel_streets/ARCHITECTURE.md`](steel_streets/ARCHITECTURE.md) for how it is
  built). It ships as a plain Godot project; nothing in `core/`, `scene/`,
  `modules/`, or the build system is aware of it.
- No engine-side patches, no custom modules, no changed defaults. Upstream
  `README.md`, `CONTRIBUTING.md`, and the CI workflows in `.github/workflows/`
  apply unchanged.

## Working in this repo

Build the editor (linking needs ~8 GB of RAM/swap):

```bash
scons tests=yes target=editor dev_build=yes -j$(nproc)
```

Run the unit tests:

```bash
./bin/godot.linuxbsd.editor.dev.x86_64 --headless --test
# single suite: --test-case="*AnimationPlayer*"
```

Run the demo with the freshly built editor binary:

```bash
./bin/godot.linuxbsd.editor.dev.x86_64 --path steel_streets
```

There is no repo-wide lint command; formatting is enforced by `pre-commit`
(`clang-format`, `ruff`, header/copyright scripts) exactly as upstream:

```bash
pre-commit install && pre-commit run --all-files
```

`pre-commit` does not cover GDScript, so `steel_streets/` changes are only
validated by opening/running the project.

## Caveats worth knowing

- `steel_streets/project.godot` targets feature level `4.3` while the engine in
  this tree is `4.7-beta`; the demo uses the deprecated `TileMap` node
  (`TileMapLayer` is the supported replacement).
- `steel_streets/assets/` is fully generated by `steel_streets/tools/gen_assets.py`
  (Pillow + `wave`). Regenerate rather than hand-editing PNGs or WAVs.
- Upstream `master` moves fast; rebase onto upstream rather than merging so the
  `steel_streets/` commit stays a clean single addition on top.
